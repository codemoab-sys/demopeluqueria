Abrir esta URL en el navegador:

http://localhost/PORTAFOLIO-PROYECTOS/TPV-Peluqueria/peluqueria/public/setup-database.php

Esto ejecutará:
- php artisan migrate:fresh --seed --force

Importante:
- Asegúrate de que la base de datos esté configurada en .env
- El proceso puede tardar unos segundos
- Si aparece un error, revisa el contenido de la salida en pantalla
